## Sourcing rules the pipeline enforces

These are not guidelines the author followed; each one is a check in code with a test behind it.

- **Only the URLs in `config/sources.yaml` are ever fetched.** There is no crawler and no link-following, so the corpus cannot grow beyond the seven pages above by accident.
- **Publisher is recorded per chunk**, and every chunk resolves to Groww. The refusal texts point at SEBI and AMFI's investor-education material, which is deliberately *not* in the corpus - those are hand-offs, not citations.
- **No third-party blog, aggregator or forum is a source.** The brief excludes them, and the list above is short enough to check by eye: two domains, `groww.in` and `amfiindia.com`.
- **Every figure is quoted, never derived.** No ratio, no return, no ranking between schemes is computed anywhere in the pipeline. The one figure that looks like an exception is in the corpus itself: one FAQ chunk on the page states the fund's average annual return since inception is 18.28%, and `rag/guardrails.py` refuses that number even though the page publishes it, because reporting it is a performance claim regardless of where it came from.
- **Fetch date is carried on every chunk**, which is what makes the `Last updated from sources: YYYY-MM-DD` stamp on an answer truthful rather than decorative.

```
python -m tools.dump               # refresh data/dump/*.txt
python -m tools.make_sources       # regenerate this file + the CSV
```

A NAV or an AUM on these pages changes without notice, so a demo run on a stale snapshot will quote figures that have moved. The stamp is there so that is visible rather than hidden.
